# Эволюционер

**Общий живущий мир:** [evo.valeriypolunovskiy.ru](https://evo.valeriypolunovskiy.ru/).
Расчёт идёт на сервере и продолжается после закрытия сайта. Телефон показывает
состояние и отправляет команды; вход и управление защищены паролем.
[Устройство сервера и сохранения](docs/server.md).

**Правила модели:** смешанное питание, наследуемая программа роста и регулируемая
помощь переходам с нулём по умолчанию.
[Отдельная модель в браузере](https://vvp310792.github.io/evolutioner/) позволяет
проводить свои опыты независимо от общего мира.
[Правила и запуск опытов](docs/open-model.md) · [Проверки](docs/verification.md).

Описанное ниже относится к **прежнему режиму**, который можно выбрать в панели
«Правила модели». Его калибровки нельзя переносить на новые правила.


[Подробное описание прежнего режима](docs/legacy-model.md).
